# Lokanta 1741 image assets

Upload the approved restaurant photography into this folder using these filenames. The page and cards already reserve the corresponding image areas.

- `card.jpg` — Restaurant Reservations listing card (recommended landscape crop, 4:3).
- `home-feature.jpg` — homepage featured restaurant panel (wide landscape, 16:9).
- `hero.jpg` — Lokanta 1741 detail-page hero (landscape, 16:9).
- `gallery-01.jpg` — main restaurant/gallery image.
- `gallery-02.jpg` — dining room or architectural detail.
- `gallery-03.jpg` — food / culinary image.
- `gallery-04.jpg` — rooftop terrace / historic domes.
- `hammam.jpg` — Cağaloğlu Hamamı image used in the cross-promotion panel.

Use original or partner-approved images. Keep image filenames stable so the website paths do not need to change when photography is replaced.
